## 🎯 Выбери свой вариант запуска

### Вариант 1 — На твоём компьютере (проще всего)

**Когда использовать:** Если хочешь быстро попробовать или твой компьютер всегда включен.

**Шаги:**
1. Открой папку `bot`
2. Убедись что `.env` заполнен твоими токенами
3. Открой PowerShell в папке `bot`
4. Выполни:
```bash
pip install -r requirements.txt
python main.py
```

**Минус:** Бот работает только пока включен компьютер.

---

### Вариант 2 — Google Cloud Run (РЕКОМЕНДУЕТСЯ)

**Когда использовать:** Нужен бот 24/7, но нет своего сервера.

**Плюсы:**
- ✅ Работает всегда, даже если выключишь компьютер
- ✅ Бесплатно (до 2М запросов/месяц)
- ✅ Автоматический публичный URL для плагина Minecraft
- ✅ Не нужен ngrok или проброс портов

**Шаги:**
Смотри подробную инструкцию в файле **[GOOGLE_CLOUD_DEPLOY.md](GOOGLE_CLOUD_DEPLOY.md)**

**Кратко:**
1. Создай проект на [console.cloud.google.com](https://console.cloud.google.com)
2. Установи Google Cloud SDK
3. Выполни одну команду:
```bash
gcloud run deploy mclink-bot --source . --region europe-west1
```
4. Получишь URL типа `https://mclink-bot-xxx.run.app` — это для плагина!

---

## 🔧 После запуска

### Проверь Telegram бота:
1. Найди бота в Telegram (имя которое дал при создании)
2. Напиши `/start`
3. Должен ответить приветствием ✅

### Проверь VK бота:
1. Зайди в свое VK сообщество
2. Напиши в сообщения сообщества: `help`
3. Должен ответить инструкцией ✅

---

## 📦 Настройка плагина Minecraft

После того как запустил бота:

**Если бот на твоём компьютере:**
- Используй ngrok или проброс портов (инструкция в README.md)

**Если бот на Google Cloud:**
- Скопируй URL который получил после развертывания
- В config.yml плагина укажи этот URL

Пример `plugins/MCLink/config.yml`:
```yaml
api:
  url: "https://твой-url.run.app"  # или http://localhost:8080 для локального
  secret: "mclink_secret_key_2024"
```

## ❓ Команды ботов

### Telegram:
- `/start` — помощь
- `/link КОД` — привязать аккаунт (код получаешь в Minecraft командой /link)
- `/unlink` — отвязать
- `/status` — проверить привязку

### VK (в личку сообщества):
- `help` — помощь
- `link КОД` — привязать
- `unlink` — отвязать
- `status` — проверить

### Minecraft (на сервере):
- `/link` — получить код для привязки
- `/linkstatus` — проверить привязку
- `/linkunlink` — как отвязать (подскажет использовать бота)

## 🆘 Если что-то не работает

1. **Бот молчит в Telegram/VK:**
   - Проверь что бот запущен (окно PowerShell не закрыто)
   - Проверь токены в `.env`
   - Посмотри логи в файле `mclink.log`

2. **Плагин не подключается к API:**
   - Проверь URL в config.yml
   - Проверь secret (должен совпадать с .env)
   - Для локального бота: проверь что порт 8080 открыт/пробит

3. **Ошибка при установке библиотек:**
   - Обнови pip: `python -m pip install --upgrade pip`
   - Попробуй: `pip install -r requirements.txt --upgrade`
