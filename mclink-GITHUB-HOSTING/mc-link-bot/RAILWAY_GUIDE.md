## 🚀 Пошаговая инструкция (5 минут)

### Шаг 1 — Загрузи код на GitHub

```bash
# В папке mc-link-bot:
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ВАШ_USERNAME/mclink-bot.git
git push -u origin main
```

Подробнее: [UPLOAD_TO_GITHUB.md](UPLOAD_TO_GITHUB.md)

---

### Шаг 2 — Зарегистрируйся на Railway

1. Зайди на https://railway.app
2. Нажми **"Login"**
3. **Войди через GitHub** (Connect GitHub account)
4. Разреши доступ

---

### Шаг 3 — Создай проект

1. В панели Railway нажми **"New Project"**
2. Выбери **"Deploy from GitHub repo"**
3. Найди свой репозиторий `mclink-bot`
4. Нажми **"Deploy Now"**

Railway начнет сборку (2-3 минуты).

---

### Шаг 4 — Добавь переменные окружения

1. Нажми на свой сервис в Railway
2. Перейди во вкладку **"Variables"**
3. Нажми **"+ New Variable"**
4. Добавь по очереди:

| Variable | Value |
|----------|-------|
| `TELEGRAM_TOKEN` | Твой токен от BotFather |
| `VK_TOKEN` | Токен VK сообщества |
| `VK_GROUP_ID` | ID группы VK |
| `API_SECRET` | `mclink_secret_key_2024` |
| `API_PORT` | `8080` |
| `DATABASE_PATH` | `mclink.db` |

5. Сохрани (Railway автоматически перезапустит бота)

---

### Шаг 5 — Получи публичный URL

1. Во вкладке **"Settings"** найди раздел **"Networking"**
2. Нажми **"Generate Domain"**
3. Скопируй URL (будет типа `mclink-bot-production.up.railway.app`)

---

### Шаг 6 — Настрой Minecraft плагин

В `plugins/MCLink/config.yml` укажи:

```yaml
api:
  url: "https://mclink-bot-production.up.railway.app"
  secret: "mclink_secret_key_2024"
```

Перезапусти сервер.

---

### Шаг 7 — Проверь работу

**Telegram:**
- Найди бота в Telegram
- Напиши `/start`
- Должен ответить! ✅

**VK:**
- Напиши в группу `help`
- Должен ответить! ✅

**Minecraft:**
- Введи `/link`
- Получи код
- Отправь боту
- Должно привязаться! ✅

## ⚙️ Дополнительные настройки

### Автозапуск

Railway автоматически перезапускает бота при падении.

### Custom Domain

Можешь подключить свой домен во вкладке **Settings** → **Networking**.

### База данных

Для постоянной базы данных добавь **PostgreSQL**:
1. New → Database → Add PostgreSQL
2. Railway создаст БД и даст переменные окружения
3. Измени код бота чтобы использовать PostgreSQL вместо SQLite

## 🆘 Проблемы

### Бот не запускается

1. Проверь логи — там будет ошибка
2. Убедись что добавлены все переменные окружения
3. Проверь что в `requirements.txt` все зависимости

### Плагин не подключается

1. Проверь что сгенерировал публичный URL в Networking
2. Проверь что URL правильный в config.yml
3. Проверь `API_SECRET` — должен совпадать
4. Посмотри логи бота — видит ли он запросы от плагина

### Закончились $5 кредиты

Railway попросит добавить карту. Можно:
- Добавить карту и платить (~$5-10/месяц)
- Или перейти на Google Cloud Run (бесплатно)
