# 🐙 Запуск на GitHub + BotHost

Эта инструкция покажет как залить код на GitHub и запустить на хостинге BotHost.

---

## 📦 Шаг 1 — Загрузка на GitHub

### 1.1 Создай репозиторий на GitHub

1. Зайди на [github.com](https://github.com)
2. Нажми **"New repository"** (зеленая кнопка)
3. Название: `mclink-bot` (любое)
4. Сделай **приватным** (чтобы токены не утекли)
5. Не создавай README, .gitignore — у нас уже есть
6. Нажми **"Create repository"**

---

### 1.2 Загрузи код

Открой **PowerShell** или **Git Bash** в папке `mc-link-bot`:

```bash
# Инициализируй Git репозиторий
git init

# Добавь все файлы
git add .

# Сделай первый коммит
git commit -m "Initial commit"

# Подключись к GitHub (замени USERNAME и REPO на свои)
git remote add origin https://github.com/USERNAME/mclink-bot.git

# Загрузи код
git branch -M main
git push -u origin main
```

**Важно:** Файл `.env` автоматически **НЕ загрузится** на GitHub (он в .gitignore) — это правильно, токены должны быть секретными!

---

## 🚀 Шаг 2 — Запуск на BotHost

### 2.1 Что такое BotHost?

**BotHost.ru** — бесплатный хостинг для Discord/Telegram ботов.

**Плюсы:**
- ✅ Бесплатный тариф (512 МБ RAM)
- ✅ Работает 24/7
- ✅ Поддержка Python
- ✅ Простая панель управления

**Минусы:**
- ⚠️ Ограничения по памяти на бесплатном тарифе
- ⚠️ Может засыпать при отсутствии активности

---

### 2.2 Регистрация на BotHost

1. Зайди на [bothost.ru](https://bothost.ru) или [bothost.me](https://bothost.me)
2. Нажми **"Регистрация"**
3. Заполни форму и подтверди email
4. Войди в личный кабинет

---

### 2.3 Создание бота на BotHost

1. В панели нажми **"Создать бота"**
2. Выбери **"Python"**
3. Название: `MCLink`
4. Тариф: **Free** (бесплатный)
5. Нажми **"Создать"**

---

### 2.4 Загрузка кода

**Вариант А — через GitHub (рекомендуется):**

1. В настройках бота найди **"GitHub"**
2. Подключи свой GitHub аккаунт
3. Выбери репозиторий `mclink-bot`
4. Ветка: `main`
5. Корневая папка: `bot`
6. Файл запуска: `main.py`

**Вариант Б — через FTP:**

1. В настройках бота найди данные FTP
2. Подключись через FileZilla или WinSCP
3. Загрузи все файлы из папки `bot/`

---

### 2.5 Настройка переменных окружения

В панели BotHost:

1. Найди раздел **"Переменные окружения"** или **"Environment"**
2. Добавь следующие переменные:

| Ключ | Значение |
|------|----------|
| `TELEGRAM_TOKEN` | Твой токен от BotFather |
| `VK_TOKEN` | Токен VK сообщества |
| `VK_GROUP_ID` | ID группы VK |
| `API_SECRET` | `mclink_secret_key_2024` |
| `API_PORT` | `8080` |

3. Сохрани изменения

---

### 2.6 Запуск бота

1. В панели найди кнопку **"Запустить"** или **"Start"**
2. Подожди 30-60 секунд
3. Проверь статус — должно быть **"Running"** (работает)
4. Посмотри логи — не должно быть ошибок

---

### 2.7 Получение URL для плагина

BotHost выдаст тебе домен типа:
```
https://твой-бот.bothost.ru
```

Или внутренний адрес для API. Узнай в панели в разделе **"Домены"**.

Укажи этот адрес в `config.yml` плагина:
```yaml
api:
  url: "https://твой-бот.bothost.ru"
  secret: "mclink_secret_key_2024"
```

## 🔄 Обновление бота на BotHost

### Если используешь GitHub:

1. Внеси изменения в код локально
2. Закоммить и запуш на GitHub:
```bash
git add .
git commit -m "Update"
git push
```
3. В BotHost нажми **"Обновить из GitHub"**
4. Перезапусти бота

### Если используешь FTP:

1. Загрузи обновленные файлы через FTP
2. Перезапусти бота в панели

- **Статистика** — использование RAM/CPU
- **Автозапуск** — включи чтобы бот запускался после падений

## ⚠️ Важные моменты

### База данных

BotHost использует **временное хранилище** — база может сбрасываться. Для продакшена:

**Вариант 1 — Используй внешнюю БД:**
- PostgreSQL на [supabase.com](https://supabase.com) (бесплатно)
- MySQL на [planetscale.com](https://planetscale.com) (бесплатно)

**Вариант 2 — Используй Google Cloud Run** (см. GOOGLE_CLOUD_DEPLOY.md) — там более стабильное хранилище.

### Порт API

BotHost может требовать специфичный порт. Если не работает:
1. Спроси в поддержке BotHost какой порт использовать
2. Измени `API_PORT` в переменных окружения

## 🆘 Проблемы и решения

### Бот не запускается

1. Проверь логи в панели BotHost
2. Убедись что все зависимости в `requirements.txt`
3. Проверь переменные окружения

### Плагин не подключается

1. Узнай правильный URL в панели BotHost
2. Проверь что `API_SECRET` совпадает
3. Проверь логи бота — видны ли запросы от плагина

### Недостаточно памяти

Бесплатный тариф BotHost дает 512 МБ RAM. Если бот падает:
1. Отключи VK бота (если не нужен) — добавь в `.env`:
   ```
   VK_TOKEN=
   ```
2. Или перейди на платный тариф
3. Или используй Google Cloud Run (бесплатно до 1 ГБ)
